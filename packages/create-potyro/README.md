# create-potyro

```sh
npm create potyro@latest my-app
cd my-app
npm install
npm run build      # → dist/my-app.potyro-app.zip
```

A folder with a [Potyro](https://potyro.app) app that packs, tests and typechecks. In Potyro, **Add an
app → From this device** installs the zip. Then follow
[Your first Potyro app](https://github.com/potyro-app/potyro/blob/main/docs/tutorials/01-your-first-app.md).

`npm create potyro@latest my-app -- --title "My app"` names the app something other than its folder.
