# __TITLE__

A [Potyro](https://potyro.app) app.

```
npm install
npm run build        # → dist/__NAME__.potyro-app.zip
npm test            # the app is valid, and its functions do what they say
npm run typecheck
```

To run it: open Potyro, **Add an app → From this device**, choose `dist/__NAME__.potyro-app.zip`,
tick **I wrote this. Run it as mine.** and **Add app**. To update it, pack again and add the zip
again: **Replace it, keep its data** keeps everything you entered.

The whole app is `__NAME__.app.ts`. Start with the tutorial: *Your first Potyro app*.
