# Welcome to Notes

Each note here is a plain **Markdown file** in this app's own folder. Nothing is locked in: open *Files* to see them, save a copy to your device, or bring your own `.md` files in.

## What a note can hold

- Headings, lists and **bold** or *italic* words
- Links, like [the Markdown guide](https://www.markdownguide.org/basic-syntax/)
- Checkboxes for things to do:
- [x] Write a first note
- [ ] Bring in the ones on my laptop

> A quote, for something somebody said that you want to keep.

```
code, kept exactly as typed
```

## Where to start

1. Tap **New note** and give it a name.
2. Write. Tap **Edit** on any note to change it.
3. **Save a copy** sends the file anywhere: a message, a folder, another app.
